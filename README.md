# Accessible Task Builder

Static browser-based accessible assessment task editor and viewer.

## Publish with GitHub Pages
1. Create a new repository (for example, `accessible-task-builder`).
2. Upload `index.html` and `.nojekyll` to the root of the `main` branch.
3. Open **Settings → Pages** in the GitHub repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main`, `/ (root)` and **Save**.
6. Open the Pages URL shown on that settings page once deployment has completed.

## Important
- Work is saved in each browser's local storage, **not** to GitHub or a shared school database.
- Staff/student modes are not authenticated access controls.
- Use the app's JSON backup/export to preserve authored tasks.
- Do not enter student names or other private information on a public demonstration website.
