# Accessible Task Builder v4: One-page landscape marking sheet

## Updating an existing GitHub Pages site

1. Extract this ZIP.
2. Upload the new `index.html` into the root of your existing GitHub repository and **replace** the old `index.html`.
3. Commit the change and allow GitHub Pages to redeploy.
4. Reload the live site with Ctrl + Shift + R if your browser still displays the earlier version.

## Changes in this update

- **Exactly one landscape A4 marking sheet per task** whenever A-E criteria exist. All standards, teacher comments and final result stay together.
- The PDF automatically adjusts rubric spacing and type size down to a legible limit. If a task still cannot fit, export stops with a prompt to shorten or combine criteria instead of splitting or silently removing them.
- The Word marking table has more compact spacing and an editable teacher-comments area. Overly large tables trigger an export warning.
- Fillable PDF A-E descriptor cells, teacher comments and final-result fields are retained.
- Student task pages and Steps for Success keep their existing format and may occupy additional portrait pages where necessary.
- The Word task converter remains in the left sidebar, directly under School Settings.

## Privacy and local tasks

Tasks are stored within each browser's local storage. The site does not contain a shared database, staff authentication or cloud synchronisation. Back up local tasks regularly.

Fidget Spinner was used as a local test task. Its task content and marking standards are not included in the public repository package. Import it separately if authorised.
