# Accessible Task Builder v8

Deploy on GitHub Pages by replacing your repository's root `index.html` with this file.

## New in v8

- The full-screen task viewer supports **Right Arrow** for Next and **Left Arrow** for Previous.
- Keys work on the task viewer only and do not interrupt typing, forms, dropdowns or pop-up dialogs.
- All existing task editing, tier variations, Word and PDF exports remain unchanged.

Browser-local task storage is retained. Back up your tasks before updating.
